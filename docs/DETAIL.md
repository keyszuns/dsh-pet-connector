# 大肥鱼世界连接器

> **不想摸鱼你还可以修仙！** 除了摸鱼、鱼本和日常养成，还可以进入独立的文字修仙秘境：八处地区按境界解锁，每场约 5 分钟，可冲击境界、修习本命功法、炼丹并服用破境丹。


把本机正在跑的 **dsh-pet** 接进「大肥鱼世界」。连接器不改 dsh-pet、不打包它的素材，
只通过 dsh-pet 自带的本地 HTTP 扩展面（`/dsh-pet-7340/*`）读状态、写打工态、让宠物说话。

## 它做什么（M3）

- **设备码配对**：右键宠物 →「打开大肥鱼世界」→ 生成配对码 → 浏览器加入 → 自动上线。
- **换电脑恢复**：大肥鱼ID + 恢复码，在网页 `/recover` 把账号接到新电脑；旧 token 立即失效。
- **加入页**：勾选协议、手动选择省/市/区、填写大肥鱼生日；**不获取定位**。
- **五行**：生日（公历年）算生肖与纳音五行；城市按大区有五行；面板显示相生/相克与经验、幸运加成。
- **班次**：选岗位（按等级解锁）与 15/30/60 分钟；**每秒真实入账**；**开溜保留已赚部分**。
- **副本**：Lv10 + 注册满 72 小时解锁，每天 2 次、每次 30 分钟；通关必得 1 件装备。
- **修仙秘境**：独立修仙等级与头衔，八处地区按境界解锁，5 分钟定时日志，手动大境界突破，本命功法，材料炼丹，丹药突破，独立修仙榜
- **装备/商店**：装备只加幸运（帽子/围巾/挂件/背景），可购买、强化、穿上；幸运影响掉落品质与副本鱼饼。
- **三 Tab 面板**：我的鱼（等级/经验/鱼饼/幸运/今日进度/班次/副本）、世界（好友 + 排行榜 + 按城市分区列出所有大肥鱼）、背包（装备与商店）。
- **本地同步**：升级播「放烟花」动画 + 冒泡；副本掉装备弹装备卡；鱼饼每 30 分钟冒泡报数；背包里可开「挂件跟随」（实验）。

## 隐私边界

- 不请求定位、不接收经纬度、不调用地图服务。
- 不读取用户文件、DSH 会话、模型密钥、剪贴板或进程。
- 只读写自己的 `~/.dsh/dsh-pet-connector/state.json`（token、平台地址、宠物名）。
- 只访问配置里的 `platformUrl` 与本机 dsh-pet 接口。
- 加入页会提示：生日是游戏设定，请勿填写本人真实生日。

## 配置项（`cordis.patch.yml` 的 `config`）

| 键 | 默认值 | 说明 |
|---|---|---|
| `platformUrl` | `http://127.0.0.1:8787` | 平台地址；公网部署改成 `https://...` |
| `petId` | `main` | 本机 dsh-pet 实例 id |
| `petName` | `大肥鱼` | 首次配对时的显示名，加入页可改 |

## 用法

1. 启动平台：`node platform/server.mjs`（默认 `http://127.0.0.1:8787`）。
2. 插件管理里启用本插件；打开任意会话。
3. 右键宠物 →「打开大肥鱼世界」→「生成配对码」→ 浏览器加入（协议 + 城市 + 生日）。
4. 回来面板自动上线；「我的鱼」里能看到等级、鱼饼、五行与幸运。

## 边界

- M1 只做登录、世界在线、资料展示；打工结算、副本、装备在 M2–M4。
- dsh-pet 的 HTTP 扩展面没有正式发布契约，升级 dsh-pet 后需回归三条链路：
  `/work-status`、`/broadcast?surface=`、`/menu/*`。
- 装备还挂不到宠物身上：dsh-pet 没有挂件接口，M1 只做背包占位；A 气泡卡 / B 坐标挂件在 M5。
